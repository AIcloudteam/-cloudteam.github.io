Cloud Computing Concepts

The technologies and principles behind our project.

Five Essential Characteristics of Cloud Computing

01. On-Demand Self-Service

Users can access computing resources whenever needed without requiring direct interaction with the service provider.

02. Broad Network Access

Cloud services are available over the internet and can be accessed through computers, smartphones and other devices.

03. Resource Pooling

Cloud providers share computing resources among multiple users according to demand.

04. Rapid Elasticity

Computing resources can increase or decrease depending on workload requirements.

05. Measured Service

Cloud resource usage is monitored and measured, allowing users to understand their consumption.

Our Practical Cloud Implementation

GitHub Pages – Website Hosting

We use GitHub Pages to publish our HTML website online. It provides a managed hosting platform without requiring us to configure our own server. It is closest to the PaaS service model.

AWS EC2 – Cost Estimation

We use the AWS Pricing Calculator to estimate the cost of hosting a similar website on an Amazon EC2 virtual server. We compare On-Demand and one-year Reserved Instance pricing.

Auto Scaling – Proposed Improvement

We propose using AWS Auto Scaling to automatically adjust the number of servers when website traffic increases or decreases. This can improve availability and performance, but it also increases infrastructure costs and complexity.

Project Outcome

Through this project, we demonstrate how a website can be deployed using a cloud platform, investigate cloud hosting costs and explore how cloud resources can be scaled to support changing demand.
